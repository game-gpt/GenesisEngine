# 数据流

本文档描述 Genesis 引擎的核心数据流和处理管道。

---

## 核心数据流概览

```
玩家行为 → 因果锚点累积 → 时空树更新 → 注意力计算
    ↓
坍缩触发 → 波函数坍缩 → 场景生成 → 渲染输出
    ↓
历史哈希更新 → 持久化存储
```

---

## 详细数据流

### 1. 玩家行为处理流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  玩家行为   │ ──→ │  行为事件   │ ──→ │ 因果锚点   │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 权重累积   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 权重传播   │
                                        └─────────────┘
```

**数据类型**：
- 输入：`PlayerAction`（玩家行为）
- 输出：`CausalAnchor`（因果锚点）

**关键步骤**：
1. 玩家行为被捕获
2. 转换为行为事件
3. 创建因果锚点
4. 累积权重到因果系统
5. 传播权重到相关节点

---

### 2. 时空树更新流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  因果锚点   │ ──→ │  节点更新   │ ──→ │ 哈希计算   │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 缓存失效   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 父节点传播 │
                                        └─────────────┘
```

**数据类型**：
- 输入：`CausalAnchor`
- 输出：`HistoryHash`（更新后的历史哈希）

**关键步骤**：
1. 因果锚点触发节点更新
2. 计算新的历史哈希
3. 失效相关缓存
4. 向上传播到父节点

---

### 3. 注意力计算流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  玩家位置   │ ──→ │  距离计算   │ ──→ │ 视角计算   │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 交互权重   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 因果权重   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 注意力等级 │
                                        └─────────────┘
```

**数据类型**：
- 输入：`Position`（玩家位置）、`Position`（视角方向）
- 输出：`AttentionLevel`（注意力等级）

**计算公式**：
```
Attention = w1/distance + w2·view_dot + w3·interaction + w4·causal_importance
```

---

### 4. 波函数坍缩流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  注意力触发 │ ──→ │  约束收集   │ ──→ │ 熵计算     │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 最小熵选择 │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 状态确定   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 约束传播   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 完成检查   │
                                        └─────────────┘
```

**数据类型**：
- 输入：`IWaveFunctionState`（波函数状态）
- 输出：`ICollapsedScene`（坍缩后的场景）

**关键步骤**：
1. 注意力等级达到阈值触发坍缩
2. 收集相关约束条件
3. 计算每个单元格的熵
4. 选择熵最小的单元格
5. 随机确定其状态
6. 传播约束到邻居
7. 检查是否完全坍缩

---

### 5. 渲染输出流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  坍缩场景   │ ──→ │  实体提取   │ ──→ │ 特征向量   │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 场景描述   │
                                        └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 渲染后端   │
                                        └─────────────┘
```

**数据类型**：
- 输入：`ICollapsedScene`
- 输出：`Frame`（渲染帧）

**关键步骤**：
1. 从坍缩场景提取实体
2. 计算因果特征向量
3. 生成场景描述
4. 传递给渲染后端

## 事件驱动架构

Genesis 引擎采用事件驱动架构，模块间通过事件进行松耦合通信。

### 核心事件类型

| 事件类型 | 触发时机 | 订阅者 |
|:---|:---|:---|
| `PlayerActionEvent` | 玩家行为发生 | Causal, Attention |
| `NodeUpdatedEvent` | 时空节点更新 | HashLife, Persistence |
| `CollapseTriggeredEvent` | 坍缩被触发 | Collapse, Rendering |
| `AttentionChangedEvent` | 注意力等级变化 | Attention, Collapse |

### 事件处理流程

```csharp
// 事件发布
public class PlayerActionHandler
{
    private readonly IEventBus _eventBus;
    
    public void OnPlayerAction(PlayerAction action)
    {
        var @event = new PlayerActionEvent(action);
        _eventBus.Publish(@event);
    }
}

// 事件订阅
public class CausalWeightSystem : IEventHandler<PlayerActionEvent>
{
    public Task HandleAsync(PlayerActionEvent @event)
    {
        // 处理玩家行为事件
        var anchor = CreateAnchor(@event.Action);
        AccumulateWeight(anchor);
        return Task.CompletedTask;
    }
}
```

## 缓存策略

### HashLife 缓存

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  演化请求   │ ──→ │  缓存查找   │ ──→ │ 命中？     │
└─────────────┘     └─────────────┘     └─────────────┘
                           │                   │
                           │ 是                │ 否
                           ↓                   ↓
                    ┌─────────────┐     ┌─────────────┐
                    │ 返回缓存   │     │ 计算演化   │
                    └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 存入缓存   │
                                        └─────────────┘
```

**缓存键**：`(NodeHash, DeltaTime)`

**缓存淘汰**：LRU 策略，优先淘汰高层级节点

---

## 持久化策略

### 增量保存

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  状态变更   │ ──→ │  哈希计算   │ ──→ │ 差异检测   │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
                                        ┌─────────────┐
                                        │ 增量存储   │
                                        └─────────────┘
```

**存储内容**：
- 节点历史哈希
- 因果锚点记录
- 坍缩场景快照

**检查点策略**：
- 自动检查点：每 N 分钟
- 手动检查点：关键事件后
- 增量检查点：仅保存变更
