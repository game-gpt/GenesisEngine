# Genesis Engine 简介

Genesis Engine 是一个专注于**涌现叙事**的游戏引擎，基于 Gnosis 元引擎构建。

## 什么是涌现叙事？

涌现叙事（Emergent Narrative）是指游戏故事不是预先写好的，而是通过系统交互**自然产生**的。Genesis Engine 通过以下机制实现：

1. **因果锚点** - 记录关键决策点
2. **波函数坍缩** - 根据玩家行为确定叙事分支
3. **注意力调度** - 动态分配计算资源到玩家关注区域

## 核心概念

### 因果锚点（Causal Anchor）

因果锚点是叙事中的关键决策点。每个锚点记录：
- 触发条件
- 可选分支
- 因果关系权重

### 波函数坍缩（Wave Function Collapse）

借鉴量子力学概念，叙事在玩家观察前处于"叠加态"，观察后"坍缩"为确定状态。

### 注意力调度（Attention Scheduling）

引擎动态追踪玩家注意力分布，优先计算玩家关注区域的内容，优化性能。

## 与 Gnosis 的关系

Genesis Engine 是 Gnosis 元引擎的**应用层**。所有底层功能（ECS、渲染、物理、音频）均由 Gnosis 提供，Genesis 专注于涌现叙事层。

```
Genesis Engine (涌现叙事层)
        ↓
    Gnosis (元引擎层)
        ↓
   操作系统 / GPU
```
