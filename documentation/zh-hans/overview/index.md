# Genesis 引擎文档

欢迎来到 **Genesis 引擎（因果引擎）** 官方文档。

## 简介

Genesis 是一套以**时空四维树**与**因果锚点系统**为核心的**因果引擎**，专为涌现式叙事、活态世界和玩家驱动的命运演化而设计。

> 世界不是一盒录像带，等你去播放。世界是一块概率云，你的每一个行为都在改变它的波函数。

## 核心概念

### 三大支柱

| 概念 | 说明 |
|------|------|
| **时空四维树** | 3D 空间 + 1D 时间的层级数据结构，支持时间跳跃与因果追踪 |
| **因果锚点** | 玩家行为对世界命运的连续权重贡献 |
| **波函数坍缩** | 从概率云中生成确定性实体的过程 |

### 注意力驱动计算

引擎将玩家的**注意力**定义为一种稀缺的计算资源：

- **屏幕空间**：最高精度模拟（L0）
- **交互范围**：高优先级更新
- **兴趣点**：次高精度模拟
- **其他区域**：低功耗概率云状态
